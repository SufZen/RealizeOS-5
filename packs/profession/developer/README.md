# Developer profession pack

For residential, commercial and mixed-use developers. Market-neutral: currency, terms, contract forms and local rules come from the market pack.

**Contents:** an English glossary mapped to core families, `payment-claim` and `tender-item` schema extensions, value-report measures, trust defaults for writes, and an investor-report template.

**Skills and agents** for this profession (tender requirements register, payment claim vs milestone, investor report, and the tenders, procurement, site and payments, and finance and investors agents) currently ship as starter files in `templates/real-estate-developer/`, which are copied into the venture when it is created. Moving them into the pack is planned once packs can supply skills at run time.

**Limits:** see `pack.yaml`. This pack prepares checks and drafts. People decide.
